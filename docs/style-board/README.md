# Style board

The images the first official heroes were made from, one folder per faction. Use them to see each faction's look before you make something for it. How each one was made, with its prompt and seed, is in [the art guide](../art-pipeline.md), section 7.

| Faction | Look | Hero | Images, in the order they were made |
|---|---|---|---|
| [Elite](elite/) | dark painted concept art, muted earthy colour; broad farming families; bone and linen accent | The Yoke | style image 020, character sheet 006, turnaround 003, the ard's turnaround 001 |
| [Swarm](swarm/) | bold graphic-novel ink, heavy black shadows; portly men in tailored suits; plum accent | The Auditor | style image 003, character sheet 002, turnaround 001 |
| [Utility](utility/) | vintage technical-manual engraving, muted washes; lean, wiry technicians; verdigris accent | The Coil Engineer | style image 003, turnaround 003 |

- **Style image:** the faction's look. A hero's character sheet is drawn from it.
- **Turnaround:** the hero from the front, sides and back on a plain background. The 3D model was made from it. Flat magenta marks the team parts, which the game paints in the team's colour.

Only images that went into a finished hero are here. The board grows as more units get official art.
